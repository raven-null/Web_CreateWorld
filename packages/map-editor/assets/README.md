# 地图编辑器素材库

> 本目录存放 `@worldmap/editor` 的**视觉素材**（纹理 / 图标 / 3D 贴图）。
> 为什么放在插件包内而不是仓库根目录：插件将来要能独立安装到别的项目，
> 素材必须跟着包走；放在 `packages/map-editor/` 里，打包时天然随包分发。

## 与项目素材库的分工（别放错）

| 素材库 | 位置 | 放什么 |
| --- | --- | --- |
| **插件级**（本目录） | `packages/map-editor/assets/` | 编辑器**渲染**要用的：地形纹理、编辑器图标、3D 贴图、编辑器自带字体 |
| **项目级** | 仓库根目录 `assets/` | 主站自己的：Logo、空状态插图、演示底图 |

判断方法：**这份素材换个项目还能不能用？**
- 「森林 / 沙漠的填充图案」「地球仪的星空背景」→ 本目录（属于编辑器）
- 「本站 Logo」「登录页插画」「拿来演示的一张世界地图」→ 项目级 `assets/`

> 演示用底图（例如导入编辑器当底图的现成世界地图）属于**项目级**，放 `assets/samples/`，
> 不要放这里——插件不该背一份几十 MB 的演示图。

## 目录约定

| 目录 | 放什么 | 当前状态 |
| --- | --- | --- |
| `terrain/` | 地形纹理、手绘图案、纸张质感（无缝平铺） | 暂无文件，现在的图案由 `src/terrain-render.ts` 程序化生成 |
| `ui/` | 工具栏与图层面板图标（SVG 优先） | 暂无文件，现在用文字标签 |
| `globe/` | 3D 地球仪用的星空背景、大气辉光、夜面灯光掩膜 | 暂无文件，待 M4（3D 地球仪）开工 |
| `fonts/` | 自带字体（如手绘地图风格的中文字体） | 暂无文件，现在用系统字体栈 |

`terrain/` 细分（按用途建子目录即可）：
- `terrain/tiles/` —— 地形填充图案，要求**四边可无缝平铺**
- `terrain/paper/` —— 纸张纤维 / 污渍 / 做旧质感
- `terrain/edges/` —— 地形边界描边所需的花边与笔触
- `terrain/legend/` —— 图例用的地形小样（与 `tiles/` 可复用同一批文件）

## 素材规格

| 项 | 约定 | 原因 |
| --- | --- | --- |
| 图标 | **SVG**，统一 `viewBox="0 0 24 24"`，线条颜色用 `currentColor` | 主题要能换深浅色，写死颜色会失效 |
| 平铺图案 | PNG，尺寸为 **2 的幂**（64 / 128 / 256 / 512） | 必须四边无缝，且要能随缩放平铺 |
| 高分辨率 | 位图按 **@2x** 再出一份（如 `tree@2x.png`） | 高分屏不糊 |
| 大图 | 优先 WebP，同时提供 PNG 回退 | 星空 / 辉光体积大 |
| 字体 | 只放**可商用**授权，同时提交同名的 `LICENSE` 文件 | 字体授权最容易踩坑 |
| 命名 | 全小写，单词用 `-` 连接，如 `snow-forest.png` | 跨平台大小写不敏感，避免踩坑 |

## 登记规则

每放进来一份素材，必须在下面「素材清单」里加一行。**没有登记的素材视为临时文件**，
可以随时被清理。

素材来源只允许三类，且必须写清：
1. **自己绘制** → 来源写「自有」
2. **开源素材** → 必须写清项目名、作者与许可证（如 CC0 / MIT / OFL）
3. **AI 生成** → 写清生成工具与提示词要点

> ⚠️ 不要放入来源不明、或授权不允许商用的图片。这个项目将来会部署到公开域名。

### 为什么同时留「拉伸」和「平铺」两份

两种铺法对应两类素材，用错会很难看：

| 铺法 | 适合的素材 | 本素材的效果 |
| --- | --- | --- |
| `stretch`（整幅拉伸） | **照片型**：一张完整的羊皮纸 / 老纸照片 | ✅ 无重复感，细节全保留（轻微拉伸看不出来） |
| `tile`（平铺） | **图案型**：花纹、织物、可无缝重复的纹理 | ⚠️ 普通照片直接平铺会出现网格接缝，必须先做镜像拼贴

## 怎么在代码里引用

素材**不参与 TypeScript 类型检查**，引用方式推荐交给构建工具解析 URL：

```ts
// 宿主（apps/web）这边导入，拿到打包后的地址，再作为 props 传进插件
import parchmentUrl from "../../../../packages/map-editor/assets/terrain/paper/parchment-full.jpg";

<MapEditor
  adapter={adapter}
  mapId={id}
  paperTextureUrl={parchmentUrl}
  paperFill="stretch" // 照片型素材用整幅拉伸；图案型素材才用 "tile"
/>
```

注意事项：
- 插件本体（`@worldmap/editor`）**不做网络请求**（CI 边界规则第 3 条）：
  素材由宿主打包进产物、把地址经 `paperTextureUrl` 传进来；
  插件内用 `Image` 加载（浏览器自己取图，不算 `fetch`）
- 生成类素材（如程序化图案）优先写成代码，只有「画不出来 / 画出来太慢」的才落地成文件：
  现在的七种地形图案就是程序化生成的，好处是零体积、可随调色板变色
- 加载失败必须能降级：纹理缺失时退回内置纸张，不能让整个编辑器白屏
  （`applyPaperTexture()` 失败时返回 `null`，调用方静默保留原纸张）
- **平铺素材不能直接平铺**：普通照片四边颜色对不上，铺开会有明显网格接缝；
  用 `createSeamlessTile()` 做镜像拼贴后再用（`applyPaperTexture()` 已经内置这一步）
