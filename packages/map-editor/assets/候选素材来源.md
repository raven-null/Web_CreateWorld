## 一、地图符号与图标（优先级最高）

现在的七种地形图案都是**程序化生成**的（波浪 / 点 / 树丛 / 沙点 / 山形折线 / 雪花 / 兜底斜线），
好处是零体积、可随调色板变色。真实素材的价值在于**观感立刻上一个档次**——手绘地图的味道主要来自这些符号。

### 17–18 世纪制图笔刷（kmalexander 系列）

奇幻地图圈子里口碑最好的一批免费笔刷，取材自真实古地图（Janssonius / de Fer / Harrewyn / Van der Aa / Zuodong 等），
每个主题一套。帖子与下载汇总在 Cartographers' Guild 及其个人站：

- [Janssonius：17 世纪制图笔刷](https://www.cartographersguild.org/printthread.php?t=46695)
- [de Fer：17 世纪制图笔刷](https://www.cartographersguild.org/printthread.php?t=50924)
- [Harrewyn：18 世纪制图笔刷](https://kmalexander.com/2019/07/29/harrewyn-a-free-18th-century-cartography-brush-set-for-fantasy-maps/)
- [Van der Aa：18 世纪制图笔刷](https://cartographersguild.net/showthread.php?t=45019)

⚠️ 形式是 **Photoshop ABR 笔刷**：要在 Web 里用，得导出成 PNG / SVG 再打包。
作者一般声明可免费用（含商业），但**下载时逐个确认一次**并记录到素材清单。

## 五、怎么用进现在的编辑器

按「改动小 → 改动大」排序：

1. **图形符号替图案**（`terrain/tiles/`）：把程序化图案换成 Kenney 的符号，铺在地形上
2. **装饰符号升级**（`terrain-render.ts` 的 `drawDecoration`）：现在画的是简化山 / 树 / 浪 / 沙丘，
   换成古地图风格的符号，观感提升最明显
3. **纸纹叠加**：在羊皮纸上叠一层细噪点或旧纸斑（低透明度 multiply），补回拉伸放大的细节损失
4. **手写地名**：接霞鹜文楷，配合「注记」标注地名的功能一起做
5. **UI 图标**：工具栏现在是文字标签，换 Kenney 图标
