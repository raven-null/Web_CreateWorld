# 项目素材库

> 本目录存放**整个项目（主站）**的素材：品牌标识、界面视觉、插图、演示图片。
> 地图编辑器插件的素材不在这里，见 `packages/map-editor/assets/`。

## 两个素材库的分工（别放错）

| 素材库 | 位置 | 放什么 | 随谁分发 |
| --- | --- | --- | --- |
| **项目级**（本目录） | `assets/` | 主站的品牌、界面、插图、演示图 | 随主站仓库 |
| **插件级** | `packages/map-editor/assets/` | 地图编辑器渲染用的地形纹理、图标、3D 贴图、字体 | **随插件包**，插件装到别的项目时要跟着走 |

判断方法：**这份素材换个项目还能不能用？**
- 「世界地图上的森林纹理」→ 插件级（它属于编辑器）
- 「本站的 Logo / 登录页插画 / 演示用世界地图」→ 项目级（它属于本站）

## 目录约定

| 目录 | 放什么 | 命名建议 |
| --- | --- | --- |
| `brand/` | Logo、字标、favicon、分享卡片底图 | `logo.svg`、`logo-mark.svg`、`favicon-32.png`、`og-cover.png` |
| `ui/` | 空状态插图、加载动画、装饰性图形 | `empty-world.svg`、`loading.svg` |
| `illustrations/` | 宣传与说明用插画 | `feature-3d-globe.png` |
| `samples/` | **演示 / 测试**用的现成图片（例如导入编辑器当作底图的世界地图） | `world-flat-4096.jpg` |

## 素材规格

| 项 | 约定 | 原因 |
| --- | --- | --- |
| 图标与 Logo | **SVG**；需要随主题变色时用 `currentColor` | 站点有深色主题，写死颜色会失效 |
| 位图 | PNG（需要透明）或 JPEG / WebP（照片类）；按 **@2x** 再出一份 | 高分屏不糊 |
| 演示图 | 单张 ≤ 2MB，最长边 ≤ 4096；放仓库前先压缩 | 仓库不是图床，超限会拖慢克隆 |
| 命名 | 全小写，单词用 `-` 连接，如 `world-flat-4096.jpg` | 跨平台大小写不敏感 |
| 字体 | 只放**可商用**授权，并附同名 `LICENSE` | 字体授权最容易踩坑 |

## 登记规则

每放进来一份素材，必须在下面「素材清单」里加一行。**没登记的素材视为临时文件**，可随时清理。

来源只允许三类，且必须写清：
1. **自己绘制** → 来源写「自有」
2. **开源素材** → 写清项目名、作者与许可证（如 CC0 / MIT / OFL）
3. **AI 生成** → 写清生成工具与提示词要点

> ⚠️ 不要放入来源不明、或授权不允许商用的图片。本站部署在公开域名上。

## 怎么引用

主站前端（`apps/web`）的静态资源有两条路，按用途选：

```ts
// 1) 参与打包：交给 Vite 解析，文件名带内容哈希，适合会被改版替换的素材
const logo = new URL("../../../assets/brand/logo.svg", import.meta.url).href;

// 2) 直接公开：从 apps/web/public/ 引用，路径固定好记，适合 favicon 这类固定地址
//    需要固定 URL 时，把文件放进 apps/web/public/ 而不是本目录
```

本目录是**素材的归档与真源**；真正要按固定路径对外提供（如 `favicon.ico`、分享卡片）的文件，
需要复制或软链到 `apps/web/public/`，因为 Vite 只把 `public/` 原样拷进产物。
