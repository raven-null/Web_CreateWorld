# UI 设计工程

> 用途：本文件是 UI 设计工作的唯一入口。所有界面设计决策、规范、页面设计要点、变更记录都写在这里；定稿后再落地到代码。

---

## 1. 设计目标与原则

| 原则 | 说明 |
|------|------|
| 气质 | 档案馆 / 编年史：克制、沉静、有阅读感，避免游戏化与过度装饰 |
| 定位 | 严肃写作工具 + 轻度沉浸感 |
| 语言 | 中文优先，排版为中文阅读体验服务 |
| 门槛 | 零语法写作，界面不出现 Markdown / 标记符号 |
| 设备优先级 | 桌面优先（写作场景）；移动端保证「能看、能搜、能简单编辑」 |

## 4. 响应式规范（移动端适配方案 · 2026-10-03 已实施）

> 实现位置：`apps/web/src/styles.css` 末尾媒体查询 + `components/Layout.tsx`（汉堡菜单）+ 表格外层 `.table-scroll`。

### 4.1 断点

| 断点 | 目标 | 规则 |
|------|------|------|
| `≤ 768px` | 手机 | 单栏布局；导航收纳；内边距 16px |
| `769px - 1024px` | 平板 | 双栏可压缩；隐藏次要信息 |
| `> 1024px` | 桌面 | 当前布局 |

### 4.2 通用规则

1. 页面内边距：28px → 手机 16px
2. 顶部导航：站点名 + 汉堡菜单（或底部导航栏，待设计决定）
3. 表格：外层 `.table-scroll` 横向滚动，不压缩列
4. 触控目标：按钮 / 链接行高 ≥ 40px
5. 弹层：宽度 `max-width: calc(100vw - 32px)`
6. Toast：手机改为顶部通栏，宽度 100%
7. 编辑器工具栏：允许换行，按钮保持 40px 高

### 4.3 各页面适配要点

| 页面 | 移动端方案 |
|------|-----------|
| 发现页 | 卡片单列；标签筛选条横向滚动 |
| 条目列表 | 分类栏改为顶部横滑 chip；条目单列 |
| 条目阅读 | 操作按钮收纳为一行 icon；正文 16px |
| 编辑器 | 顶栏两行（标题行 + 状态/按钮行）；工具栏横滑 |
| 关系图 | 高度减小；图例折行；触控拖拽已支持 |
| 时间线 | 卡片全宽；弹层表单单列 |
| 地图 | 高度 `60vh`；标记表单全宽 |
| 管理后台 | 表格横向滚动；操作按钮换行 |

## 6. 工作流

1. **先文档后代码**：设计变更先写入本文件（含理由），定稿后再改 `apps/web`
2. **语义化类名**：延续现有 `.btn` / `.card` / `.tag-chip` 风格，不引入随机命名
3. **变量优先**：颜色、圆角、间距优先用 `:root` 变量，避免散落硬编码
4. **本地预览**：`pnpm dev` → http://localhost:5173，热更新即时看效果
5. **发布**：`pnpm deploy`
6. **变更记录**：每次设计改动在本文件末尾登记
