## 2026-10-03

### fix · 侧边栏贴边与切页提速
- 根因：生产数据库初始位于美西（WNAM），跨境查询导致每次切页等待 0.5–1.5 秒
- 已将生产数据库整体迁移到**亚太（APAC）**区域（新建库 + 导出/导入数据，零丢失）
- 世界区侧边栏改为**贴边布局**：宽版容器、全高侧边栏、内容区独立留白；条目编辑页保持居中
- 条目列表首屏不再等待 300ms 防抖（仅搜索输入防抖），切分类立即加载
- API 层新增 **GET 10 秒短缓存 + 并发请求合并**：页面来回切换秒开；任何写操作立即清空缓存

### feat · 世界区侧边栏导航
- 世界内页面统一左侧边栏（条目 / 关系图 / 时间线 / 地图 / 全文搜索 / 世界设置），移动端为顶部横滑 chips
- 条目编辑页保持独立全宽（写作专注）；世界主页移除重复入口按钮（保留「参与编写 / 举报」）
- 新增 `WorldLayout` 布局组件，`App.tsx` 路由改为嵌套结构

### feat · 提示文案全面中文化
- better-auth 登录 / 注册 / 改密码的英文报错统一映射为中文（新增 `lib/auth-errors.ts`）
- 服务端全量扫描确认无英文错误文案

### feat · 移动端适配
- ≤768px：汉堡菜单、分类栏横滑、表格横向滚动、编辑器两行顶栏与横滑工具栏、Toast 通栏、触控目标 ≥40px、卡片单列
- ≤1024px：平板布局微调

### docs · UI 设计工程文档
