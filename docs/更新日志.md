### docs · 地图编辑器方案（第五版：白板自由尺寸 + 视图缩放与改尺寸）
- 白板尺寸由「四档固定」改为**自由输入**：宽度 512~16384（**默认 2048×1024，已定案**，自动规整到 128 的倍数），**高度自动为一半**；界面上只有一个宽度输入框
- 明确唯一硬约束是 **2:1**：等距圆柱投影下 360°:180° = 2:1，只有保持它，「平面白板 = 完整球面贴图」才成立（3D 无缝）、**像素才是正方形**（比例尺与测量才简单）；不做任意长宽比矩形，理由与代价写进 §5.1
- 新增 §5.6 区分两件容易混淆的事：**视图缩放（看，不碰数据）** vs **白板改尺寸（变，重采样 + revision +1）**——界面文案分开、文档分开
  - 视图缩放改为**自由连续**（适应窗口 ~ 32×，原为整数倍），含光标锚点缩放、按区间切换采样（`< 1×` 开平滑 / `1~8×` 像素完美 / `≥ 8×` 可选平滑）、URL 带 `?lon=&lat=&z=`、触屏单指画 + 双指缩放并行
  - 白板改尺寸：新尺寸校验与规整、**最近邻重采样**（调色板索引图不能用双线性，会产生不存在的中间色）、分批上传、体积与细节损失预览、×2 幂次缩放**完全无损**、矢量对象与标记不受影响（存经纬度 / 比例）、`k₀` 与面积统计自动重算
- 尺寸与画质的关系写清：白板尺寸决定**信息容量上限**（后期无法凭空造细节），新建时用表格摊开「每个尺寸能画到什么程度」；非整数倍放大会锯齿但不会增加信息，想提质应当重画

- 尺度预警**阈值可调、可整体关闭**（§7.7.1）：三档预设（按地球常识 / 宽松 / 关闭）+ 逐条自定义阈值，配置存在**地图级**（`maps.scale_hints`，因一个账号下可能同时有类地球世界与超大陆世界）；关闭只静音「常识判据」，**客观读数（实距 / 面积 / 变形倍率 / 比例尺）始终显示**，避免用户失去判断依据；「知道了」可静音该条 30 天；判定逻辑是 `map-core` 纯函数（输入统计 + 配置，输出提示列表），可单测

### docs · 地图编辑器方案（第三版：比例尺与尺度系统）
- 新增需求「画图时要让用户知道已画区域有多大，避免造出庞然大物」，落地为**第 7 章比例尺与尺度系统**
- 核心结论：**等距圆柱投影下比例尺随纬度变化**（每 1° 经度实距 = `(πR/180)·cos(lat)`，每 1° 纬度恒定），因此不能放一根固定比例尺条，必须按光标纬度实时换算；由 2:1 白板推出「像素是正方形」，基准量统一为 `k₀ = πR / W`（赤道每像素实距）
- **天体半径是尺度的唯一参数**（`maps.radius_km`，默认地球 6371 km，含火星 / 月球 / 自定义）：半径改变**不影响已画内容**（数据存经纬度），无需重绘与迁移
- 明确两处投影陷阱并给出正确算法：① 屏幕直线≠球面测地线 → 距离用 haversine；② 像素面积随纬度衰减（`k₀²·cos(lat)`）→ 面积必须按纬度带加权，不能用「像素数 × 常数」
- 首期尺度能力：自适应比例尺条、光标实距与变形倍率读数、天体半径设定、笔触与图层面积统计（增量维护，绝不扫全图）、测量工具（折线距离 / 方位角）、真实世界对照（≈1.4 个澳大利亚）、尺度预警（陆地 >15% 非阻断提示）；二期做球面多边形面积与大圆航线
- 新增 §7.9 八项可测验收（含「地球 + 2048 白板：赤道 9.77 km/px、北纬 60° 经度方向 4.89 km/px，误差 <1%」等），并写入「尺度换算错误比没有比例尺更糟」的风险对策
- 全文重新编号：新增比例尺自成一章后，各章顺延为 1~18 章，交叉引用同步校正

### docs · 地图编辑器方案（第二版：球面白板 + 多图层 + 双端一致）
- 需求升级三项并已并入方案：① 白板**长宽有限制**（定尺全球白板，默认 2048×1024，2:1 一套经纬网，可选 1024×512 / 4096×2048 / 8192×4096）② 白板可**转成 3D 地球仪**③ 白板**支持多图层**（政治 / 军事 / 宗教 / 民族…，图层可自由增删）

### fix · 乱码数据修复（数据迁移编码问题）
- 现象：世界设置等页面中文显示为乱码
- 原因：数据库迁移到亚太时，导出文件经 PowerShell 默认编码读入导致中文损坏
- 处理：改用原始导出文件按 UTF-8 重新处理，清空业务数据后重新导入；新旧库逐字节比对一致（数据零丢失）

### fix · 侧边栏贴边与切页提速
- 根因：生产数据库初始位于美西（WNAM），跨境查询导致每次切页等待 0.5–1.5 秒
- 已将生产数据库整体迁移到**亚太（APAC）**区域（新建库 + 导出/导入数据，零丢失）
- 世界区侧边栏改为**贴边布局**：宽版容器、全高侧边栏、内容区独立留白；条目编辑页保持居中
- 条目列表首屏不再等待 300ms 防抖（仅搜索输入防抖），切分类立即加载
- API 层新增 **GET 10 秒短缓存 + 并发请求合并**：页面来回切换秒开；任何写操作立即清空缓存
