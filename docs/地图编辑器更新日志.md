## 登记规则（开工前先读）

1. **一条一事实**：每条写清「做了什么 + 怎么验证的」，不写「优化了体验」这种无法验收的话
2. **必须登记的四类事件**
   - 里程碑达成（M1~M5）→ 标注阶段与验收结论
   - **对内接口变更**（`MapHostAdapter` / `MapEditor` props / `cwt1` 格式 / 快照格式）→ 必须单独成条，并说明是否破坏兼容
   - **服务端接口变更**（`/api/maps/*`）→ 记录路径与影响范围
   - **坑与决策**：踩到兼容性、性能、跨端问题时记录「现象 → 原因 → 处理」，这类内容对后来者价值最高
3. **与提交对应**：提交信息用中文 `类型: 简述`（如 `feat: 白板创建与瓦片读写`），提交信息与本文件条目一一对应
4. **不记流水账**：重构到一半、调试过程不必登记；只登记「对项目状态有影响」的结果

## 2026-10-09 · M1 地基（进行中）

### M1 · feat · `cwt1` 瓦片编解码（T5 前半）
- 新增 `packages/map-core/src/cwt1.ts`：`encodeTile` / `decodeTile` / `isTileEmpty` / `createNativeGzip`，格式为 `魔数 CWT1 + 宽高(小端) + 压缩标识 + 负载`
- 关键设计：**压缩器由调用方注入**（`GzipCompressor` / `GzipDecompressor`），因此旧 WebView 缺 `CompressionStream` 时可退化为原始字节（压缩标识位 0），解码端不受影响；`createNativeGzip()` 基于标准 `CompressionStream`，浏览器 / Workers / Node 三处通用，零新依赖
- 两条保护：压缩后反而更大时自动退回原始字节；解码时校验魔数、尺寸上限（256）、解压后长度与尺寸一致
- 怎么验证的：新增 `cwt1.test.ts` 共 13 项（往返一致、头部字节、gzip 生效与体积、随机数据不可压缩、魔数错 / 过短 / 未知标识 / 缺解压器等非法输入），全部通过。**这份测试同时替代「两端互测」**——编解码器只有一份且在零依赖的 map-core 里，网站与 Worker 共用

### M1 · fix · 比例尺基准量系数写错（文档与实现同错，已由测试锁定）
- 现象：验收项「白板横向总长 = 40030 km」失败；`k₀` 若按 `πR/W` 计算，2048 白板的赤道每像素为 9.77 km，横向总长只有 20016 km（正好少一半）
- 原因：横向一整圈覆盖 360° 经度，长度是**圆周 `2πR`**，不是 `πR`；正确的基准量是 **`k₀ = 2πR / W = πR / H`**（W = 2H 时两式等价，这也正是「像素是正方形」的含义）
- 处理：修正 `scale.ts` 的系数与方案文档 §7.2 的公式；文档表格原值（2048 档 19.6 km/px）本就是对的，是公式写反了
- 怎么验证的：新增断言「赤道 19.55 km/px」「横向 40030 km」「纵向 20015 km」「4096 档为 2048 档的一半」「北纬 60° 为一半」，全部通过

### M1 · fix · 整图面积系数（同源错误）
- 现象：整块白板填满时面积只有 4πR² 的 1/4（偏 −75%）
- 原因：与上一条同源，`pixelAreaKm2` 依赖 `k₀`，系数随之翻倍
- 处理：`pixelAreaKm2 = k₀²·cos(lat)`，加权求和 `Σ count·k₀²·cos(lat)`；整图填满 = 4πR²（实测偏差 0.000%）
- 附带修正两处测试期望值本身写错的地方：球面三角形的退化对顶边用例、以及比例尺条「像素宽度单调递增」的断言方向（刻度是离散的，像素宽度只保证稳定，不保证严格递增）

### M1 · fix · 自身实现的箭头函数闭包坑（`clamp` 默认值）
- 现象：球面多边形面积对 90°-90°-90° 三角形算出 1/3 球面（应为 1/8），与内联同样公式的结果不符
- 原因：辅助函数 `clamp(value, min, max)` 在实现 `clampDot` 时把 `[-1, 1]` 误夹成 `[0, 1]`，导致 `acos` 把所有 `dot < 0` 的球面角都算成 90°
- 处理：拆出独立的 `clampDot`（点积裁剪）与 `clampHalfAngle`（半角裁剪），不再共用一个宽容的 `clamp`；同源的「半角忘除 2」错误一并修掉
- 教训：几何辅助函数不要复用「通用 clamp」，各写各的语义更安全——这一类错误在视觉上完全看不出来，只能靠已知特例的测试兜住

### M1 · chore · 球面多边形面积（二期功能）暂缓
